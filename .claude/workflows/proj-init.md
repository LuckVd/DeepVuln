# Proj-Init Workflow

1. Read `CONSTITUTION.md`.
2. Detect whether the invocation is structured flags or a freeform brief.
3. Parse the design document or freeform project description.
4. Write `INIT_SOURCE`, `project.yaml`, `CURRENT_GOAL`, `CURRENT_TASKS`, `INBOX`, and `ROADMAP`.
5. Initialize structure-contract, sync-rule, file/API/function/model docs, and dependency map.
6. Produce `docs/reports/init-latest.md` as a derived init record.
7. Archive replaced planning files when reinitializing.
