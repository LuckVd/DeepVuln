# Proj-ReadProject Workflow

1. Default to a short execution snapshot.
2. Read `project.yaml`, `CURRENT_GOAL.yaml`, `CURRENT_TASKS.yaml`, `INBOX.yaml`, latest change intent, and cleanup notes.
3. Summarize project, current focus, action board, structure-sync state, readiness, and one immediate next action.
4. If the user asks for more detail, switch to `--full`.
5. In `--full` mode, also include roadmap focus, acceptance criteria, latest derived reports, and workspace risks.
